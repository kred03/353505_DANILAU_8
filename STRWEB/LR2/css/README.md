# CSS Стили для Лабораторной Работы 2

## Структура файлов

- `style.css` - Основные стили, типографика, базовые компоненты
- `components.css` - Компоненты и специфичные стили
- `pages.css` - Стили для специфичных страниц
- `animations.css` - Анимации и прелоадер
- `selectors.css` - Дополнительные селекторы
- `pseudo.css` - Псевдоклассы и псевдоэлементы

## Реализованные требования

### ✅ Селекторы
- **Селекторы элементов**: `body`, `h1`, `p`, `img`, `nav`, `ul`, `li`
- **Селекторы атрибутов**: 
  - Начинающиеся с подстроки: `[class^="btn-"]`, `[href^="mailto:"]`
  - Заканчивающиеся подстрокой: `[class$="-primary"]`, `[href$=".pdf"]`
  - С конкретным значением: `[type="text"]`, `[lang="ru"]`
- **Селекторы классов**: `.btn`, `.card`, `.container`, `.widget`
- **Комбинации селекторов**: 
  - Объединение: `h1.primary, h2.primary`
  - Потомки: `nav ul`, `section > h2`
  - Дочерние: `article > header`

### ✅ Псевдоклассы
- **Ссылки**: `:link`, `:visited`, `:hover`, `:active`
- **Фокус**: `:focus`
- **Позиционирование**: `:first-child`, `:last-child`, `:nth-child()`
- **Состояния форм**: `:required`, `:disabled`, `:valid`, `:invalid`, `:checked`

### ✅ Псевдоэлементы
- **Первая буква/строка**: `::first-letter`, `::first-line`
- **Контекстное содержимое**: `::before`, `::after`
- **Маркеры списков**: Unicode символы (🐾, 🌿, 🦋)
- **Выделение текста**: `::selection`

### ✅ Техники макета
- **Flexbox**: Сотрудники на странице контактов
- **Grid**: Каталог на главной странице
- **Позиционирование**: Фиксированная навигация, абсолютное позиционирование статьи

### ✅ Адаптивный дизайн
- **Медиа-запросы**: Для экранов 768px и 480px
- **Адаптивная типографика**: Размеры шрифтов
- **Гибкие сетки**: Grid с `auto-fit`

## Использованные CSS свойства

### Текст и шрифты
- `font-family`, `font-size`, `font-weight`, `line-height`
- `text-align`, `text-transform`, `letter-spacing`
- `text-indent`, `text-shadow`
- `word-spacing`, `word-break`, `hyphens`

### Позиционирование
- `position: fixed`, `position: absolute`, `position: relative`
- `display: flex`, `display: grid`
- `float`, `clear`

### Фоны и границы
- `background-image`, `background-gradient`
- `border-image` с вендорными префиксами
- `box-shadow`

### Анимации
- `@keyframes`, `animation`
- `transform`, `transition`

### Адаптивность
- `@media` запросы
- `max-width`, `min-width`
- `flex-wrap`, `grid-template-columns: auto-fit`

## Браузерная совместимость

Использованы вендорные префиксы для:
- `border-image`: `-webkit-`, `-moz-`, `-o-`
- `transform`: `-webkit-`, `-moz-`, `-ms-`
- `transition`: `-webkit-`, `-moz-`, `-o-`

## Цветовая схема

```css
--primary-color: #2c5530    /* Темно-зеленый */
--secondary-color: #4a7c59  /* Зеленый */
--accent-color: #8b4513     /* Коричневый */
--text-color: #333          /* Темно-серый */
--bg-color: #f8f9fa         /* Светло-серый */
--white: #ffffff            /* Белый */
```
